# Magpie brand assets

The supplied `logo.png` is used unchanged in the application. `bird.ttf` is the supplied Bird identity font, self-hosted and used for the Magpie wordmark. UI text uses the device's readable sans-serif font.

| Colour | Hex |
| --- | --- |
| Near Black | #030812 |
| Midnight Navy | #001330 |
| Deep Ocean Blue | #002C46 |
| Petrol Teal | #004447 |
| Dark Cyan | #005454 |
| Ice White | #F1F6FC |

`magpie.svg` is a lossless SVG container embedding the supplied raster illustration; it is not a vector tracing. This preserves the supplied artwork exactly. The application favicon uses the same supplied illustration. A native vector source can replace the embedded illustration when available.

The supplied artwork and font remain subject to their owner's original licensing; the GPL license for Magpie code does not relicense them. Confirm redistribution rights before publishing these supplied assets.
